NYP Mobile Events Manager

A mobile app where students and lecturers browse campus events, sign up and host their own. The phone on this page runs the app as designed for the project poster, so you can tap around and try it.

Try it in under a minute

Use the phone above. Everything runs in your browser, so there's nothing to install or sign up for.

  1. Browse and sign up

    Tap any event on Events@NYP to see venue, dates and details, then tap Sign Up.

  2. Check the calendar

    Tap Events Calendar. Pink days have events; tap one, or use the yellow arrows to change month.

  3. Host your own

    Tap Login (any ID works), then Host. Your event appears in the list and on the calendar.

How it's built

A React single-page app talks to a Laravel REST API over JSON. Eloquent models map to five MySQL tables with foreign keys between them.

Client
React 16 app
HashRouter screens: events, add event, edit event, users
JSON
API
Laravel 5.8
Resource routes under /api, five controllers, token auth scaffold
Eloquent
Data
MySQL / MariaDB
Migrations for users, categories, events, registrations, feedback

About this demo

  • The phone shows the app as it was designed. It's a working web prototype of the screens on the 2019 project poster, built with the project's own images and real event posters.
  • The project's code is in the repo. The React frontend is in frontend/, the Laravel API in backend/ and the MySQL schema in database/. The original React build also runs here.
  • Your sign-ups and events stay on your device. They're saved in your browser only. Use Reset data under the phone to start over.
